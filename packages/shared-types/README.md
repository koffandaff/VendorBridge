# shared-types

TypeScript types shared between the frontend (`frontend/`) and backend (`backend/`).

## Usage

```bash
npm install # from repo root - the workspace is linked as @hackathon/shared-types
```

```ts
import type { SomeType } from "@hackathon/shared-types";
```

## Build

```bash
npm run build --workspace @hackathon/shared-types
```

Intentionally empty until the first cross-stack types exist.
