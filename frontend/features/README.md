# features

Application features live here. Each feature is self-contained:

```
features/<feature>/
├── components/    feature components
├── hooks/         feature hooks
├── api/           feature API calls
├── schemas/       feature validation schemas
├── types.ts       feature types
└── constants.ts   feature constants
```

Intentionally empty. No business features exist yet - directories are created when a feature is actually introduced.
